Animal Medical Center — website source code
==========================================

This folder is the full editable source for the AMC preview website
currently live at: https://amc-journey.vercel.app

What is included
----------------
- All page writing and layout files
- Interactive animals and dog-paw cursor code
- Entrance experience, Care Areas, and other sections
- Images and entrance media that live with the site

What is not included
--------------------
- node_modules (install tools recreate this on your computer)
- Temporary build folders
- The large remote pet picture sequence (those frames still load from Kindred on the live site)

How to open this on your computer
---------------------------------
1. Unzip this folder.
2. If you have a developer on your team, give them this folder. They can open it in a code editor and run the project with the usual Node / Next.js setup.
3. If you only want a copy for safekeeping, unzipping and keeping the folder is enough. You do not need to run it to own the files.

If you want a GitHub private repo or a one-click download link instead, ask in chat and we can set that up next.
